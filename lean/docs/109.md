# Integer multiplication below n log n

The following describes the scope of the Lean formalization related to the following accompanying paper(s):

- [Integer multiplication below n log n](../../preprints/Integer-multiplication-below-n-log-n-September-23-2026/paper.pdf)

## Scope

This is a partial formalization. It does not prove the main theorem, the $O(n(\log n)^{1-\kappa})$ bound on a multitape Turing machine. Instead, it checks the finite objects and the arithmetic that fix $\kappa=2^{-182}$.

| Paper | Lean (`OAI/Computability/IntegerMultiplication/`) |
| --- | --- |
| §3: $v$, $N$, $m$, $I$, $z_{\rm b}$, $z_{\rm c}$, $W_{\rm b}$, $W_{\rm c}$, $s_{\rm b}$, $s_{\rm c}$ at $h=100$; $L/N=100/539$ and $101/539$; both deficits | `Networks.values_h100`, `ratios_h100`; `neighbours_small` checks the neighbour counts directly at $h=8$ |
| `lem:motif-residuals`, rank budget | `data_wires`, `scratch_wires`, `rank_sums`, `sb_eq`, `sc_eq` |
| `lem:scalar-motifs` | `Motifs.schedule_spec` (for arbitrary scratch values); `bit_net` and `complex_net` (on the triples of any finite ground set, the paper's copy, gather, side-injection and scatter maps satisfy $\mathcal J\mathcal V+\mathcal R\mathcal G=I$); `three_stages` |
| `eq:explicit-motif-exponents` | `Exponents.bit_exponent`, `complex_exponent`: $s/W<m^{1-2^{-50}}$ for both networks |
| §4: three shears interchange $H$ and $D$ | `Motifs.three_shears` |
| `eq:phase-C`, `eq:phase-basic-identities` | `Kernels.C_eq_HSH`, `H0_eq`, `C_sq`, `C_four`, `C_inv`, `Cinv_conj`, `C_conj` |
| `eq:eight-packed-additions` and `eq:eight-packed-result` | `PackedGadget.cycles`, `gadget_spec`. Every intermediate point is within two of the start; the paper uses the bound four. |
| §5 guard constants | `Guard.guard_nu` ($m^{10}<B<m^{11}$, so $\nu=11$), `guard_C1`, `guard_count`, `guard_chain`, `guard_bound` |
| `eq:fixed-parameters`, `tab:costs`, `eq:margin-list` | `Assembly.layer_conditions`, `dimension_conditions`, `powers_eq`, `margin_values`, `min_margin` ($\min g_i=g_2=2^{-181}=2\kappa$) |

Not formalized:
- the tape-machine constructions and their running times (§2, §4–§7);
- the label nondegeneracy and residual bases of §3, beyond the counts above;
- the cited Harvey–van der Hoeven results.
