# Milne's rationality conjecture for abelian varieties

This note describes the scope of the Lean formalization related to the following paper:

- [Milne's rationality conjecture for abelian varieties](../../preprints/Milnes-rationality-conjecture-for-abelian-varieties-October-7-2026/paper.pdf)

## Scope

This is a partial formalization. It does not prove the main theorem: Mathlib has no isocrystals, p-adic Hodge theory, comparison isomorphisms or Shimura varieties. Instead, it checks the algebraic steps of the proof. The paper's [audit](../../preprints/Milnes-rationality-conjecture-for-abelian-varieties-October-7-2026/AUDIT.md) covers the rest.

| Paper | Lean (`OAI/AlgebraicGeometry/MilneRationality/`) |
| --- | --- |
| `lem:pairing-functorial` | `Transport.pairing_transfer`: the pairing equals a value computed from rational data, so it is the same in every realization; `rational_solution` |
| The rational pullback `f^* = N^{-2r}(Nf)^*` | `exteriorPower_map_smul`, `minor_smul` |
| §3: the trace tensor, its multiplier, and the normalization of the similitude scalar | `trace_restriction`, `trace_multiplier`, `inverse_bivector_scaling`, `u_eta_normalization`, `similitude_rational` |
| §3: the similitude character is primitive | `primitive_quotient_torsionfree` |
| `lem:lift-hom`: Grothendieck–Messing does not apply at `p = 2` | `two_adic_divided_power`, `two_adic_divided_power_pow` (`v₂(2ⁿ/n!) = s₂(n)`, which is `1` at `n = 2^k`) |
| `lem:avoidance` | `Avoidance.avoidance` (base-`N` uniqueness `kexp_injective`, degree bound `kexp_le`); the degree `[K₁(θ):K₁] = q` is a hypothesis |
| `thm:filtration`, the reduction to stable subobjects | `Filtration.largest_maximizer`, `maximizer_stable` (any lattice with a strictly monotone bounded dimension) |
| `thm:filtration`, the block Newton bound and the similitude determinant | `block_newton`, `similitude_det` |
| `thm:filtration`, the pairing `B(x,y) = β(x,uy)` | `twisted_skew`, `twisted_e`, `twisted_u2`, `twisted_similitude` (`eq:filtration-u-similitude`) |

Not formalized:
- Hodge classes and their specializations;
- the crystalline and étale comparisons;
- the transport through integral models of Shimura varieties and CM lifting (§3);
- weak admissibility and Lagrangian genericity (§4);
- the Weil-class dichotomy (§5) and the reduction of CM classes to Weil classes (§6);
- the companion CM Hodge theorem.
