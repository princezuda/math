# The rational Hodge conjecture for CM abelian varieties

This note describes the scope of the Lean formalization related to the following paper:

- [The rational Hodge conjecture for CM abelian varieties](../../preprints/The-rational-Hodge-conjecture-for-CM-abelian-varieties-October-6-2026/paper.pdf)

## Scope

This is a partial formalization. It does not prove the main theorem: Mathlib has no Hodge structures, algebraic cycles, theta series or p-adic Hodge theory. Instead, it checks the finite and algebraic steps of the proof. The paper's [audit](../../preprints/The-rational-Hodge-conjecture-for-CM-abelian-varieties-October-6-2026/AUDIT.md) covers the rest.

| Paper | Lean (`OAI/AlgebraicGeometry/HodgeCM/`) |
| --- | --- |
| `lem:trace-descent`, `eq:cycle-descent` | `Descent.scalar_descent` (finite Galois `K/ℚ`, any `L`-subspace `P`) and `cycle_descent` |
| Polarization `ψ_v(x,y) = Tr(ξ x c(y))` of `U(v)` | `polarization_alternating`, `polarization_nondegenerate` |
| `lem:toric-cm`, (iii) ⇒ (i) | `Signs.toric_rank_one` |
| `prop:switch-reduction`, the two-row switch chain | `Switch.switch_connected`; `Main.switch_reduction_combinatorics` restates it without auxiliary definitions |
| Pohlmann balance, as used there | `split_balance`, `switch_balance`, `pair_balance` |
| `eq:transition-composition`: the sign `(-1)^{p(p-1)/2}` and the codimension | `Signs.regroup_sign` (any anticommuting families in a ring), `transition_codim` |
| `lem:switch-normalization` | `switch_dichotomy`, `translate_odd`, `translate_conj` (needs `c` central), `unique_normalized` (`s = 1`) |
| `prop:surface-switch`: `K = (-1)^6 t_α ⊗ t_β` and the degree counts | `surface_sign`, `surface_degrees` |
| §7 (`06-assembly`): the line signs `dᵢ(τ) = vᵢ(τ⁻¹)` | `inverse_signs` |
| §4 (`04-theta`): `alt₂`, the `K`-cocycle, the sign switch at each place, the sparse tail bound, the Steinberg commutator | `Theta.alt₂_polar`, `alt₂_pure`, `alt₂_same_line`, `K_cocycle`, `sign_switch`, `sparse_tail`, `steinberg_commutator` |
| §5 (`05b-frobenius`): the ordinary-neighbour cancellation | `Arithmetic.frob_neighbors` |
| §6 (`05b-satake-frobenius`): the radial minuscule actions and the reciprocal parameter | `radial_minuscule`, `satake_inverse` |
| §6 (`05b-satake-frobenius`): the valuation bookkeeping `∑ d(τ) val = -M d(g⁻¹)` | `valuation_sum` (needs `c` central) |
| §6 (`05c-cm-types`): the cubic Frobenius relation, Weil-weight selection, extreme slopes, pure filtration | `frob_poly`, `absorb_central`, `weil_selection`, `slope_of_sign`, `extreme_slope`, `pure_filtration` |
| `lem:filtered-hecke-summands` | `wa_split` |
| `lem:cc:realization` | `exists_cm_types`, `idem_prod_ne` |

Not formalized:
- Hodge structures, cycle classes and Lefschetz (1,1), including the surface criterion beyond its signs;
- the Weil representation and the analysis of the theta construction (§4);
- the moduli spaces, integral models and the Albanese Frobenius relation (§5);
- crystalline comparison and weak admissibility as theorems (§6);
- all cited results.
